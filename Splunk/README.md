# CSA303 Lab 2 – Splunk Incident Investigation

## Overview

This repository contains my **CSA303 Digital Forensics and Incident Response Lab 2**, which focused on investigating a historical cybersecurity incident using **Splunk Enterprise** and the **BOTS v3 dataset**. The objective was to identify suspicious activity, perform cross-source correlation, reconstruct the incident timeline, and develop a detection prototype based on the investigation findings.

---

## Objectives

The investigation involved:

- Analysing multiple log sources using Splunk Search Processing Language (SPL).
- Identifying suspicious entities and validating investigative hypotheses.
- Reconstructing a cross-source incident timeline.
- Creating a Splunk investigation dashboard.
- Developing and validating a historical detection rule.
- Documenting findings, recommendations, and incident response considerations.
