# Endpoint SIEM Engineering with Wazuh, Windows and Sysmon

## Overview

This repository contains my **CSA303 Endpoint SIEM Engineering Laboratory**, which focused on deploying and configuring **Wazuh**, **Sysmon**, and a **Windows endpoint** to monitor, investigate, and detect suspicious endpoint activity. The laboratory demonstrated how endpoint telemetry can be collected, analysed, correlated, and used to develop custom detection rules for common attacker techniques.

---

## Objectives

The laboratory involved:

- Configuring Sysmon telemetry collection within Wazuh.
- Establishing baseline endpoint behaviour.
- Generating controlled security events using PowerShell.
- Investigating encoded PowerShell, CertUtil and Scheduled Task activity.
- Performing event correlation and timeline reconstruction.
- Developing and validating custom Wazuh detection rules.
- Documenting investigation findings and security recommendations.
