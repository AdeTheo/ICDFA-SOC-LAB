# Microsoft Sentinel Azure Activity Monitoring and Incident Response Lab

## Overview

This repository contains my **CSA303 Microsoft Sentinel Security Monitoring and Incident Response Lab**, which focused on deploying **Microsoft Sentinel** within Microsoft Azure to monitor Azure Activity Logs, detect Azure resource management activities, and investigate security incidents. The objective was to configure a cloud-native SIEM environment, perform log analysis using **Kusto Query Language (KQL)**, develop scheduled analytics rules, and validate the complete incident detection and response workflow.

---

## Objectives

The laboratory involved:

- Create a Log Analytics workspace and enable Microsoft Sentinel.
- Connect Azure Activity through the current supported workflow and verify ingestion.
- Use KQL to analyse control-plane events and entity context.
- Generate safe, reversible Azure activity without exposing a workload.
- Create and validate a scheduled analytics rule that returns TimeGenerated.
- Triage an incident, document evidence and complete cost-safe cleanup.

This laboratory was completed using a **Microsoft Azure for Students** subscription for educational purposes. The activities documented in this repository do not represent malicious activity or a production cloud environment.
