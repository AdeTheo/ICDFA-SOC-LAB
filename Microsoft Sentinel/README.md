Microsoft Sentinel Azure Activity Monitoring and Incident Response Lab
Overview

This repository contains my CSA303 Microsoft Sentinel Security Monitoring and Incident Response Lab, which focused on deploying Microsoft Sentinel within Microsoft Azure to monitor Azure Activity Logs, detect suspicious management operations, and investigate security incidents. The objective was to configure a cloud-native SIEM environment, perform log analysis using Kusto Query Language (KQL), develop scheduled analytics rules, and validate the end-to-end incident detection and response process.

Objectives

The laboratory involved:

Deploying Microsoft Sentinel and a Log Analytics Workspace.
Configuring Azure Activity Log collection for security monitoring.
Generating authorised Azure management events for analysis.
Investigating Azure Activity Logs using Kusto Query Language (KQL).
Creating and validating a scheduled analytics rule for Azure resource deletion detection.
Performing incident triage, event correlation, and case documentation.
Cleaning up laboratory resources and verifying successful resource removal.
